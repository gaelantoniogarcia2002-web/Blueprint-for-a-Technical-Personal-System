Mapa del sistema

Un núcleo mínimo que desova subsistemas

Este prototipo es la maqueta de un sistema personal autosostenible: una "hormiga reina" —un bucle PDCA de revisión semanal— que, una vez automatizada, libera capacidad cognitiva para crear e ir soltando trabajadoras especializadas (PARA, GTD, entorno). Baja por el corte para probar cada cámara con datos reales tuyos; todo se guarda solo en este navegador.

¿Para qué sirve y cómo se usa?

Sirve para probar, durante un par de semanas, si un sistema personal mínimo —solo una revisión semanal bien hecha— te ordena la cabeza antes de invertir tiempo en construir algo más grande. No hace falta usar las seis cámaras desde el primer día: empieza solo por la Cámara real y el Túnel de captura.

  1. Túnel de captura: durante la semana, cada vez que algo te ronde la cabeza, entra aquí y anótalo en segundos. No lo clasifiques todavía.
  2. Cámara real, una vez por semana: define tu bucle de hábito (cuándo, cómo, con qué recompensa), corre el sprint de 5–15 min y responde Verificar / Actuar-Planificar / Hacer. Guarda la revisión al final.
  3. Depósito PARA y Corredores GTD: cuando tengas un momento, abre el Túnel de captura y decide, item por item, si cada cosa es un proyecto/área/recurso/archivo (PARA) o una acción atada a un contexto (GTD).
  4. Panel de colonia: revisa aquí tu racha y qué tanto de lo capturado ya procesaste; es la prueba de que el bucle de refuerzo está funcionando de verdad.

Todo se guarda solo en este navegador (localStorage): si cambias de dispositivo o borras datos del sitio, se pierde. Es intencional — esto es un prototipo de prueba, no el sistema final.
